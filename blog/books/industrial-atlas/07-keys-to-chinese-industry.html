第二卷·第一章 理解中国工业的钥匙

第一卷画的是全球地图。第二卷要放大中国。 在放大之前，先回答一个问题：中国工业为什么长成今天这个样子？

1.1 数据框：先看规模

GDP            ：134.9 万亿元（2024，+5.0%）
全部工业增加值 ：40.5 万亿元（2024）
制造业增加值   ：33.6 万亿元（2024）
全球地位       ：制造业增加值占全球接近 30%，连续 15 年全球第一
装备制造业     ：增加值 +7.7%，占规上工业 34.6%
高技术制造业   ：增加值 +8.9%，占规上工业 16.3%
新能源汽车     ：产量 1288.8 万辆（中汽协口径；统计局规模以上口径 1316.8 万辆）
工业机器人     ：2024 年新安装 29.5 万台，占全球 54%（IFR）

来源：国家统计局《2024 年国民经济和社会发展统计公报》、中汽协、IFR《2025 世界机器人报告》。

1.2 五把钥匙

理解中国工业，不需要复杂理论，只需要五把钥匙：

1. 规模钥匙：世界上最大的单一工业市场
2. 纵深钥匙：从螺丝钉到航空发动机，几乎什么都造
3. 地方竞争钥匙：城市之间互相竞争，长出一个个“产业特区”
4. 工程师红利钥匙：每年数百万理工科毕业生进入制造业
5. 政策之手钥匙：五年规划、补贴、产业基金，直接画地图

钥匙一：规模

中国是全球最大的汽车市场、最大的机器人市场、最大的光伏和电池市场、最大的家电市场。

规模带来三个结果：

1. 成本摊薄：任何新技术只要在中国量产，成本下降速度就是全球最快
2. 应用场景：自动驾驶、机器视觉、协作机器人都能先在中国找到客户
3. 迭代速度：一年迭代三次，竞争对手三年迭代一次

钥匙二：纵深

联合国产业分类中，中国拥有全部工业门类。这意味着：

一部手机     ：电池、屏幕、模具、PCB、镜头、芯片封装，全部能在珠三角+长三角找到
一辆电动车   ：从锂矿加工到电机电控到智能座舱，全部能在国内完成
一条产线     ：PLC、伺服、减速机、传感器，国内都有替代供应商

纵深不是“什么都能造”的骄傲，而是“被卡脖子时有人能顶上”的缓冲。

钥匙三：地方竞争

中国工业地图的真正画法，不是“国家→产业”，而是“城市→产业特区”：

深圳：电子 + 新能源 + 机器人
合肥：显示 + 存储 + 新能源汽车
常州：新能源 + 减速器
宁波：模具 + 汽配 + 单项冠军
武汉：光电子 + 存储 + 汽车
长沙：工程机械
西安：半导体 + 航空

每一座城市都在争取同一个东西：产业链上的位置。 这种竞争效率极高，也造成重复建设。

钥匙四：工程师红利

中国每年毕业的理工科大学生数量世界第一。它们不全是顶尖人才，但数量保证了：

1. 研发工程师可以“堆”出来
2. 现场工程师可以“补”出来
3. 售后服务工程师可以“派”出去

这是德国双元制之外的另一种人才体系：大学教育 + 企业内训 + 项目实战。

钥匙五：政策之手

中国工业地图上许多节点，是政策画出来的：

合肥模式：政府用产业基金“赌”京东方、长鑫、蔚来
深圳模式：市场自己长出来，政府做配套
苏州模式：政府把外资工厂“请”进来，再本地化

三种模式没有优劣，只有适合的产业阶段。

1.3 中国版“隐形冠军”：专精特新

德国有 Hidden Champion，中国有对应的体系：

德国隐形冠军 中国专精特新“小巨人”
定义 细分市场世界前三、营收低于约 50 亿欧元、知名度低 专业化、精细化、特色化、新颖化的中小企业
数量 全球约 2700 家（德国占最多） 国家级“小巨人”约 1.4 万家（2025 年工信部口径，约数）
典型 SEW、Balluff、Wittenstein 纳博特斯克中国工厂的邻居、双环传动、绿的谐波等
路径 家族企业 + 全球化 + 百年积累 市场 + 工程师 + 政策扶持 + 十年追赶

中国“小巨人”的意义：第一卷里的那些隐形冠军，中国正在一个一个地“复刻”。

1.4 五把钥匙的局限

规模   → 但高端环节（光刻、EDA、高端轴承）仍是短板
纵深   → 但“全”不等于“精”，卡脖子恰恰在最精的地方
地方竞争 → 但重复建设、产能过剩
工程师红利 → 但顶尖人才密度仍低于德日
政策之手 → 但政策也会画错地图

第二卷的目标，不是赞美或批评中国工业，而是精确画出它现在长什么样。
