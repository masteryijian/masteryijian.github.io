# GitHub Pages 真实市场研究

2026-10-16：移除不存在的同源 /api/analyze 调用、计时假进度、固定比例成本报价、失败后冒充报告的模板，以及旧版 CRM 数据写入。

静态站使用个人 OpenAI API 直连。密钥仅保留当前页内存，不写 localStorage、导出、日志或仓库。该模式限可信个人设备，不适合作为共享客户服务的密钥方案。资料发送须勾选同意；API 费用由所填密钥承担。没有密钥时仅提取资料、复制/下载待评估包。没有配置服务器模型密钥，不能宣称已经上线免配置 AI 服务。不更新 Netlify。

真实流程：原文审阅 → 强制 web_search 的公开研究 → 12章商业评估 → 证据修订。只有真实成功搜索、至少两条可追踪URL、12章和最小篇幅满足时才交付；这是结构门槛，不代表事实准确性或专业审签。报告与证据JSON统一来源。网络搜索阶段仅提供用户填写的公开产品、类别、行业，不提供私人客户名、报价和原文；分析阶段发送完整文本。PDF标页、文本标行；180000字符以上拒绝而非静默截断。扫描件/OCR失败明确阻断。

论证参照灵心巧手欧洲市场与代理报告：执行结论、企业可信度、产品技术、市场需求、竞争与替代、客户与决策、商业经济性、合规与责任、代理与合作、实施路线、尽调问题、最终建议。每篇重查事实，不沿用旧案例内容。

验证：npm test，包含无搜索拒绝、短报告拒绝、HTTP失败、截断防护、四次调用链、密钥不进入导出、私人资料不进入搜索输入。模型调用使用模拟响应验证；由于没有实际API密钥，真实报告质量和浏览器API连通性未验证。
